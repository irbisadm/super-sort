# Security Policy

## Supported versions

super-sort ships **no runtime dependencies** and performs no I/O, so its real attack surface
is minimal. Security fixes, if ever needed, land on the latest published version only.

| Version | Supported |
| ------- | --------- |
| latest  | ✅         |
| older   | ❌         |

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

- Preferred: GitHub [private vulnerability reporting](https://github.com/irbisadm/super-sort/security/advisories/new).
- Or email **i@irbisadm.dev**.

You can expect an acknowledgement within a few days.
